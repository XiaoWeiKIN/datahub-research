# Official Documentation Learning Notes

官方文档：https://docs.datahub.com/

## 定位

这里保存官方材料的中文学习笔记，但不做逐字镜像。

每篇笔记回答五件事：

1. 官方在说什么？
2. 它提出了什么 architectural claim？
3. 这个 claim 背后的设计哲学是什么？
4. 对 AI Context Layer 有什么意义？
5. 哪些内容是产品叙事，哪些可以抽象成通用架构原则？
